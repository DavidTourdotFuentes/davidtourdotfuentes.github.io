# Fichiers du SDK FMOD

Copier ici, depuis le SDK **FMOD Engine HTML5** (dossier `api/studio/lib/wasm/`) :

- `fmodstudio.js`
- `fmodstudio.wasm`

Prendre le build **sans threads** : GitHub Pages ne permet pas les en-têtes COOP/COEP.
Utiliser une version du SDK compatible avec la version de FMOD Studio qui exporte les banks.
